# Jurnal OverTheWire

Catatan perjalanan saya menyelesaikan wargame di [OverTheWire](https://overthewire.org/) — platform gratis untuk belajar dasar-dasar cybersecurity lewat permainan bertingkat (level).

> Semua materi soal adalah milik komunitas **OverTheWire** (https://overthewire.org). Jurnal ini hanya catatan belajar pribadi.

## Aturan Umum OverTheWire

Diringkas dari halaman [Rules](https://overthewire.org/rules/):

1. **Hormati semua orang** — tidak ada pelecehan atau diskriminasi.
2. **Tidak boleh spam / promosi diri** di chat atau pesan pribadi.
3. **Jangan spoiler** — kalau minta bantuan di chat, sebutkan game dan levelnya, nanti dibantu lewat pesan pribadi.
4. **Jangan pakai nama file/folder yang gampang ditebak**, dan hapus file yang kamu buat setelah selesai.
5. **Untuk pembuat konten / writeup: JANGAN publikasikan kredensial (password) game.** Writeup dan tutorial boleh, password tidak.
6. **Beri kredit** — sebutkan komunitas OverTheWire dan cantumkan link websitenya.

> Karena aturan no. 5, semua password di jurnal ini **disensor** (`[DISENSOR]`). Yang ditunjukkan hanyalah cara dan bukti bahwa password berhasil didapat.
